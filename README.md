# Каталог детских праздников

Сайт-презентация с анимацией, квестами и шоу: 15 программ, фотографии и видео.

Сайт: https://gvukamolle.github.io/mikhail-party-catalog/

## Локальный просмотр

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173/. Сайт работает на обычных HTML, CSS и JavaScript.

## Публикация

GitHub Pages публикует корень ветки `main`. После отправки изменений сайт обновляется автоматически.
