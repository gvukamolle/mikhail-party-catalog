# Каталог детских праздников

Сайт-презентация с анимацией, квестами, шоу и мастер-классами: 21 программа, 23 фотографии и 11 видеороликов.

В программах доступны полный состав, продолжительность и стоимость. Видео размещены последовательно, с индивидуальными обложками на основе кадров. Плеер содержит play/pause и полосу перемотки; при включении следующего ролика предыдущий останавливается. Фотогалерея находится на белой подложке, фон каталога — светлый лиловый.

Сайт: https://gvukamolle.github.io/mikhail-party-catalog/

## Локальный просмотр

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173/. Сайт работает на обычных HTML, CSS и JavaScript.

## Публикация

GitHub Pages публикует корень ветки `main`. После отправки изменений сайт обновляется автоматически.

Цена стандартной анимации — от 6 900 ₽, VIP — от 10 900 ₽. Продолжительность каждой — 60 минут. В каталоге использованы новые фотографии шоу пузырей, Tesla и «Угадай напиток».

В разделе «Шоу» доступна сахарная вата: 24 000 ₽, 30 минут. Пять мастер-классов: тай-дай, мишки Bear Brick, роспись футбольных мячей и бейсболок, изготовление слаймов. Каждый длится 30 минут, цены указаны «от». В мобильной версии четыре категории размещены в два ряда.
